## Огляд

Інструмент виконує моніторинг доступності RouterOS API, збір метрик трафіку та виконання тестів пропускної здатності каналів. Використовує кешування в межах прогону для обробки зібраних даних та аналізу стану мережі з урахуванням локальних fail-safe гілок.

## Поведінка

1. Система виконує періодичну діагностику доступності RouterOS API. При успішному підключенні оновлюється статус мережі, фіксується стан контролера та актуалізується таймлайн активного каналу. При втраті зв'язку запускається механізм повторного підключення з інтервалом.
2. Для моніторингу трафіку збираються пасивні вимірювання з інтерфейсів. Дані згладжуються за часовим вікном для відображення середнього навантаження на канали.
3. При запуску тесту швидкості система виконує завантаження тестових обсягів даних через кожен канал окремо. Результати порівнюються для оцінки реальної пропускної здатності.
4. Система збирає події перемикання каналів та стан планувальника з логів роутера. На основі отриманих даних формується автономний звіт, що включає стан API, параметри контролера, дані DHCP, маршрутизації та релевантні записи системного логу.
5. Для глибокої діагностики доступний перегляд сирих записів логу з можливістю текстового фільтрування.
6. Звітність та історія зберігаються у локальному сховищі пристрою для збереження контексту між сесіями.

## Гарантії поведінки

- Містить локальні fail-safe гілки; інші помилки можуть поширюватися назовні.
- Кешує результати в межах одного прогону.

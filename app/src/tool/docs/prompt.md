## Огляд

Генерує системний промпт за допомогою `createSystemPrompt` для агента моніторингу WAN на маршрутизаторах MikroTik з ідентифікацією каналів `LMT` та `Bite`. Надає інструкції щодо перевірки доступності, трафіку та тестів швидкості, забезпечуючи відповіді у форматі `plain-text`.

## Поведінка

1. Формує системний промпт для агента моніторингу WAN на маршрутизаторах MikroTik.
2. Встановлює правила ідентифікації каналів: WAN1 називається LMT, WAN2 — Bite.
3. Визначаляє межі повноважень: використання інструментів лише для перевірки доступності, трафіку, стану відмовостійкості та запуску тестів швидкості без зміни конфігурації.
4. Встановлює порядок взаємодії: виконання одного інструмента за раз, очікування результату та уточнення нечітких запитів.
5. Визначає формат фінальної відповіді: лаконічне резюме у форматі plain-text.

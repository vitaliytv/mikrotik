## Огляд

Файл надає інструменти для перевірки доступності API RouterOS та стану планувальника Dual-WAN. Використання [TOOLS] дозволяє отримувати метрики трафіку та проводити вимірювання пропускної здатності.

## Поведінка

1. Перевірка доступності API RouterOS, стану кінцевих точок, затримки відповідей, здоров'я планувальника, валідності скриптів та активного WAN-з'єднання.
2. Отримання поточного стану планувальника Dual-WAN, пріоритетів DHCP-маршрутів, стану зондів здоров'я активного WAN та останніх подій перемикання.
3. Читання поточної миттєвої швидкості прийому та передачі біт за секунду для обох WAN-інтерфейсів.
4. Вимірювання пропускної здатності завантаження через завантаження файлів з Cloudflare для оцінки швидкості з роутера з подальшим видаленням тимчасових файлів.

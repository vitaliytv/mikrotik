## Огляд

Дірка для контрактної перевірки MCP-інтеграції `wan-monitor` у `mcp`-режимі через `.mcp.json`.

Конфіги, на які спирається код: `.mcp.json`

Секція фіксує, що зовнішній процес стартує за цим конфігом, у відповідь експонує лише дозволені tools для `wan-monitor`, а стан WAN читається в придатному для перевірки вигляді з MCP-взаємодії.

Read-only: не пише у файлову систему чи БД.

## Поведінка

1. Запускає окремий `wan-monitor` у `mcp`-режимі як зовнішній процес, щоб перевірити поведінку інтеграції так само, як це робить MCP-оркестратор через `.mcp.json`.
2. Підключається до цього процесу через MCP-stdio і звіряє, що доступні лише потрібні tools для взаємодії.
3. Виконує запит на читання поточного WAN-стану, щоб підтвердити, що tool-виклик доходить до сервісу і повертає керований результат.
4. Приймає як валідний лише завершений або помилковий статус відповіді, щоб відсікти неочікувані проміжні стани.
5. Завершує перевірку без записів у файлову систему чи БД, оскільки сценарій є read-only.

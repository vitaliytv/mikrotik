## Огляд

Точка входу запускає настільний застосунок моніторингу WAN і передає виконання основному модулю застосунку. У випускній збірці для Windows вона вимикає появу зайвого консольного вікна, щоб користувач взаємодіяв лише з графічним інтерфейсом. Модуль працює в режимі лише читання й не записує дані у файлову систему чи базу даних.

## Поведінка

1. Запускає desktop-застосунок моніторингу WAN через основний модуль застосунку.

2. У release-збірці для Windows працює без додаткового консольного вікна, щоб користувач бачив лише інтерфейс застосунку.

3. Не виконує власних операцій із файловою системою чи базою даних; усю подальшу поведінку визначає модуль застосунку.

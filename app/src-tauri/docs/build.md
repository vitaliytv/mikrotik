## Огляд

Файл перевіряє, що застосунок готовий до стандартного Tauri build-циклу без записів у файлову систему чи базу даних. Він потрібен, щоб підготувати запуск збірки в межах штатного процесу, не додаючи кешування чи побічних змін.

## Поведінка

1. Запускає збірку Tauri для підготовки застосунку до компіляції.
2. Делегує всі перевірки та генерацію збіркового артефакту стандартному процесу Tauri.
3. Не змінює файлову систему чи базу даних.

## Огляд

CLI-вхід для отримання стану й виконання дій у цьому наборі інструментів. Команда або виводить доступні можливості, або запускає обрану дію, або переходить у mode для зовнішньої інтеграції через JSON-відповідь.

Режим роботи визначається командним викликом і повертає структурований результат, придатний для автоматизації. Помилки не пробиваються назовні: вони перехоплюються та перетворюються на безпечний вихід із маркером помилки, щоб не ламати інтеграцію.

АНКОРИ: CLI-вхід, JSON-відповідь, fail-safe, error-marker

## Поведінка

1. Приймає команду з CLI й обирає один із режимів роботи: показ доступних інструментів, показ схем, виконання інструмента, запуск agent-запиту або підняття MCP-сервера.
2. Для довідкових режимів повертає структурований JSON зі списком інструментів або їхнім описом, щоб зовнішні системи могли швидко інспектувати можливості агента.
3. Для режиму виконання інструмента запускає потрібну дію, друкує результат у JSON і позначає помилку процесу, якщо виконання завершилося неуспішно.
4. Для agent-режиму збирає намір користувача, визначає актора й надсилає запит у агентний контур для отримання відповіді у форматі, придатному для автоматизації.
5. Якщо намір не задано, показує коротку підказку щодо доступних режимів і завершує роботу з помилкою.
6. У MCP-режимі піднімає stdio-сервер із двома бізнес-операціями: почати новий запит і продовжити запит, який потребує уточнення.
7. MCP-сервер приймає звернення від зовнішнього оркестратора, виконує відповідну агентну дію й повертає результат як JSON-текст.
8. Якщо запит містить невідому операцію або під час обробки стається помилка, повертає fail-safe відповідь у форматі помилки без винесення винятку назовні.
9. Працює без запису у файлову систему чи базу даних; взаємодіє з мережею через підключений chat-контур.
10. Якщо запуск завершується поза очікуваним сценарієм, виводить помилку в консоль і ставить код завершення процесу.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
